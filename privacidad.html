Política de privacidad

parque-central-sync · Última actualización: 19 de octubre de 2026

1. Datos a los que accede la aplicación

Con la autorización expresa del usuario, la aplicación solicita únicamente permisos de solo lectura:

  • spreadsheets.readonly: leer el contenido de hojas de cálculo de Google.
  • drive.readonly: consultar la fecha de modificación de archivos y descargar hojas de cálculo en formato Excel.

La aplicación solo procesa los archivos específicos configurados por su operador. No lee correos, contactos, calendario ni otros archivos del usuario, y no crea, modifica ni elimina nada en Google Drive.

2. Uso de los datos

El contenido leído se usa exclusivamente para alimentar una base de datos privada y tableros de indicadores operativos de uso interno. Los datos no se venden, no se comparten con terceros, no se usan con fines publicitarios y no se usan para entrenar modelos de inteligencia artificial.

3. Almacenamiento y seguridad

Los datos y las credenciales de acceso (token de OAuth) se guardan en el equipo y en la base de datos del operador, con acceso restringido. No se envían a servidores de terceros distintos de Google.

4. Uso limitado

El uso y la transferencia de la información recibida de las API de Google por parte de esta aplicación se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

5. Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, la aplicación deja de leer los archivos de inmediato.
